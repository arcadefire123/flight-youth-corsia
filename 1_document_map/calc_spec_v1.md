## 2. 산식 정의

### 모듈 `fuel_use` — 항공편별 연료 사용량

공통 사항
- 출력 단위: 톤(t)
- 부피(L)로 측정된 급유량은 밀도를 곱해 질량으로 변환한다. 밀도는 실제값 또는 `DENSITY_STD`.
- 모든 항공편을 **시간 순으로 정렬한 뒤** 계산한다. 국내선/국제선 구분은 **항공편별 연료 사용량을 계산한 후에** 수행한다 (ETM 3.1.4.4 주).
- 5가지 방법 사이에 우열이 없다. EMP에서 승인된 방법 하나를 준수기간 내내 적용한다 (ETM 3.1.4).

---

**C-01 · 방법 A**

```
F_N = T_N − T_(N+1) + U_(N+1)
```

| 변수 | 의미 | 단위 |
|---|---|---|
| `F_N` | 항공편 N의 연료 사용량 | t |
| `T_N` | 항공편 N 급유 완료 후 탱크 내 연료량 | t |
| `T_(N+1)` | 후속 항공편 N+1 급유 완료 후 탱크 내 연료량 | t |
| `U_(N+1)` | 후속 항공편 N+1의 급유량(부피×밀도) | t |

- 국제 근거: SARPs App.2 §2.2 / ETM 3.1.4.1
- 국내 근거: **지침 별표2 제1호**
- 예외 1: 해당 항공편 또는 후속 항공편에 급유가 없으면 `T`는 그 항공편의 **블록오프 시점 연료량**으로 대체한다.
- 예외 2: 항공편 N 이후 탱크 비우기를 포함한 정비 등 비행 외 활동을 하면 `T_(N+1) + U_(N+1)`을 **후속 활동 시작 시 탱크 잔량** 또는 technical log의 블록온 연료량으로 대체할 수 있다.
- 예외 3: 타 운영사 항공편을 임시(ad-hoc) 수행하는 운영사는 Block-off/Block-on 방법으로 측정값을 제공한다.
- 주의: `T_N`(급유 후 탱크 내 연료)은 블록오프 연료와 **다른 값**이다. 혼동이 가장 흔한 오류다 (ETM 3.3.5.4.2).
- 데이터 완전성: 국내선↔국제선이 연속되는 구간에서는 국제선 사용 연료를 분리하기 위해 항공편 N과 후속편 N+1의 자료가 **둘 다** 필요하다. 자료 누락을 피하려면 Block on 연료 또는 국제선 항공기의 급유 후 탱크 연료량을 항상 기록할 것을 권장한다 (지침 별표2 제1호 주3).
- 급유량 출처: 연료 공급 장부 또는 영수증에 기록된 연료공급업체의 측정자료를 사용한다 (지침 별표2 제1호 주2).
- 필요 데이터: 항공편 N + 항공편 N+1

---

**C-02 · 방법 B**

```
F_N = R_(N−1) − R_N + U_N
```

| 변수 | 의미 | 단위 |
|---|---|---|
| `R_(N−1)` | 직전 항공편 N−1 종료 시(블록온) 탱크 잔량 | t |
| `R_N` | 항공편 N 종료 시(블록온) 탱크 잔량 | t |
| `U_N` | 항공편 N의 급유량 | t |

- 국제 근거: SARPs App.2 §2.3 / ETM 3.1.4.2
- 국내 근거: **지침 별표2 제2호**
- 예외: 직전 비행이 없는 경우(신규 도입, 정비 직후) `R_(N−1)`을 technical log의 직전 비행 종료 시 잔량으로 대체할 수 있다.
- 데이터 완전성: 국내선↔국제선 연속 구간에서는 항공편 N과 **직전** 항공편 N−1의 자료가 둘 다 필요하다 (지침 별표2 제2호 주3).
- 급유량 출처: 연료 공급 장부 또는 영수증에 기록된 연료공급업체의 측정자료 (지침 별표2 제2호 주2).
- 필요 데이터: 항공편 N + 항공편 N−1

---

**C-03 · Block-off / Block-on**

```
F_N = T_N − R_N
```

| 변수 | 의미 | 단위 |
|---|---|---|
| `T_N` | 항공편 N 블록오프 시 탱크 연료량 | t |
| `R_N` | 항공편 N 블록온 시 탱크 잔량 | t |

- 국제 근거: SARPs App.2 §2.4 / ETM 3.1.4.3
- 국내 근거: **지침 별표2 제3호**
- 정의: 블록오프 = 마지막 도어가 닫히고 첫 엔진이 켜지기까지. 블록온 = 마지막 엔진 정지와 첫 도어 개방 사이. 이 정의에서 벗어나면 EMP에 명시하고 승인받아야 한다.
- 필요 데이터: 항공편 N만

---

**C-04 · 연료 급유량(Fuel Uplift)**

후속 항공편에도 급유가 있는 경우 (= 배분 불필요):

```
F_N = U_N
```

후속 항공편 N+1 … N+n 에 급유가 없는 경우, **항공편 N 자신을 포함해** 블록타임에 비례 배분:

```
F_N     = U_N × [ BH_N     / (BH_N + BH_(N+1) + … + BH_(N+n)) ]
F_(N+1) = U_N × [ BH_(N+1) / (BH_N + BH_(N+1) + … + BH_(N+n)) ]
F_(N+n) = U_N × [ BH_(N+n) / (BH_N + BH_(N+1) + … + BH_(N+n)) ]
```

- 국제 근거: SARPs App.2 §2.5 / ETM 3.1.4.4
- 국내 근거: **지침 별표2 제4호** (원문 이미지 대조 확인, 2026-09-22)
- **구현 주의: 배분 대상에 급유한 항공편 N 자신이 포함된다.** 급유편이라고 해서 `F_N = U_N`이 되는 것이 아니다. `F_N = U_N`은 후속편에도 급유가 있어 배분 구간이 항공편 N 하나뿐일 때의 결과일 뿐이다 (분자·분모가 모두 BH_N이므로 비율 1). ETM 표 3-6의 3번 항공편(U=26.9, BH=3.1)이 `F=20.8`로 나오는 것이 이 때문이다.
- 예외: 배분 대상에 **국내선 항공편이 섞여 있어도 배분은 그대로 수행**한다. 국내선 제외는 배분 후에 한다.
- 밀도: 급유량이 부피로 제공되면 밀도를 곱해 질량으로 변환한다 (지침 별표2 제4호 주1).
- 급유량 출처: 연료 공급 장부 또는 영수증에 기록된 **연료공급업체의 측정자료**를 사용한다 (지침 별표2 제4호 주1 후단).
- 구현 주의: 분모가 0이 되는 경우(모든 BH가 0 또는 결측)를 가드한다.
- 필요 데이터: 항공편 N + 이후 무급유 연속 구간 전체의 블록타임

**C-05 · 블록시간을 이용한 연료 할당**

```
AFBR_(AO,AT) = Σ U_(AO,AT,N) / Σ BH_(AO,AT,N)
F_N = AFBR_(AO,AT) × BH_(AO,AT,N)
```

| 변수 | 의미 | 단위 |
|---|---|---|
| `AFBR` | 운영사·기종별 평균 연료 연소율 | t/블록시간 |
| `U` | 급유량 방법으로 결정된 국제선 급유 연료량 | t |
| `BH` | 국제선 블록타임 | 시간 |

- 국제 근거: SARPs App.2 §2.6 / ETM 3.1.4.5
- 국내 근거: **지침 별표2 제5호**
- **반올림: AFBR은 최소 소수점 셋째 자리까지 반올림** (지침 별표2 제5호 2) 주3). 국내 명시 규칙이므로 단위테스트에 반드시 넣는다.
- 옵션 분기: 국제선·국내선 급유를 명확히 구분할 수 있으면 국제선 실적만으로 AFBR 계산, 구분할 수 없으면 해당 기종 전체 항공편으로 계산.
- 제약: 기종별 급유 데이터가 없는 운영사는 이 방법을 쓸 수 없다.
- 데이터 갭 처리: 갭이 있는 항공편은 **AFBR 계산에서 제외**하고, 그 항공편은 CERT로 추정한다. AFBR을 갭 항공편에 적용하지 않는다.
- 기종 코드: 항공기 유형은 **ICAO Doc 8643 Aircraft Type Designators**를 사용한다 (지침 별표2 제5호 1) 주2).
- 검증 요구: 외부 검증기관의 검증보고서에 사용된 각 ICAO 지정 항공기 유형별 AFBR 평가가 포함되어야 한다 (지침 별표2 제5호 2) 주2).
- 추가 요구: 검증기관은 보고된 배출량이 운영사의 다른 연료 관련 자료와 비교해 타당한지 **교차 점검**해야 한다 (지침 별표2 제5호 말미). → 검증 규칙 X-26

### 모듈 `co2` — 이산화탄소 배출량

**C-06 · CO₂ 환산**

```
CO2 = Σ_f ( M_f × FCF_f )
```

| 변수 | 의미 | 단위 |
|---|---|---|
| `M_f` | 사용된 연료 f의 질량 | t |
| `FCF_f` | 연료 f의 연료전환계수 | tCO₂/t |

- 국제 근거: SARPs Part II Ch.2
- 국내 근거: **영 별표3 제1호** (5만톤 이상), 제3호 (5만톤 미만은 선택)
- 계수: Jet-A / Jet-A1 / TS-1 / No.3 = 3.16 · AvGas / Jet-B = 3.10
- 적용 대상: 국제운항만. 의료·소방·구호 목적 국제운항은 제외 (법 제2조5 단서, 규칙 제2조).
- 주의: 적격연료(SAF)로 인한 배출량 계산도 **해당 연료형식에 상응하는 일반 항공유의 연료전환계수**를 쓴다 (지침 별표4 5.2 비고2). 즉 SAF라고 배출량이 0이 되는 게 아니라, 감축은 C-10에서 따로 처리한다.

**C-07 · CERT 적용 판정**

| 조건 | 결과 |
|---|---|
| 상쇄의무 대상 국제선 연간 CO₂ ≥ 50,000 t | 연료사용량 모니터링 방법 **의무** (지정 최초 연도 제외) |
| < 50,000 t | CERT 사용 가능 |
| 2019~2020년 구간 | 기준이 **500,000 t** |
| 데이터 갭 항공편 | 방법과 무관하게 CERT로 추정 |

- 국제 근거: SARPs App.3, Part II Ch.2 2.2.1
- 국내 근거: **지침 제3조③ 단서, 제4조②③, 별표1 제4호 a, 별표3**
- 전환 규칙: 5만톤 미만으로 감소 → 다음연도 **9/30**까지 변경 EMP 제출 가능(임의). 5만톤 초과 → 같은 기한까지 제출 **의무**. 둘 다 승인 다음연도 1/1부터 적용.
- 엔진 구현: CERT 자체는 ICAO 배포 도구이므로 재구현하지 않는다. 판정 로직과 입력 데이터 준비(기종·출도착 공항·블록타임 또는 대권거리·편수)까지만 구현하고, 배출량 값은 외부 입력으로 받는다.

### 모듈 `offsetting` — 연도별 상쇄의무량

**C-08 · 연도별 상쇄의무량**

```
OR_y = %S_y × ( OE_y × SGF_y ) + %O_y × ( OE_y × OGF_y )
```

| 변수 | 의미 | 단위 |
|---|---|---|
| `OR_y` | 연도 y의 상쇄의무량 | t |
| `OE_y` | 연도 y의 상쇄의무 대상 CO₂ 배출량 | t |
| `%S_y` | 부문별 백분율 | % |
| `%O_y` | 개별 백분율 = 100% − %S_y | % |
| `SGF_y` | ICAO 부문 성장계수 | % |
| `OGF_y` | 운영사 개별 성장계수 (C-09) | % |

- 국제 근거: SARPs 3.2.1 / 3.2.2, Table 3.1
- 국내 근거: **지침 제9조①, 별표6 제2호·제3호** (원문 이미지 대조 확인, 2026-09-22)

| 적용 연도 | %S | %O | 출처 |
|---|---|---|---|
| 2021.1.1 ~ 2023.12.31 | 100% | 0% | SARPs 3.2.1에만 존재. **국내 지침 별표6 제3호에는 없음** |
| 2024.1.1 ~ 2029.12.31 | 100% | 0% | SARPs Table 3.1 |
| 2030.1.1 ~ 2032.12.31 | 100% | 0% | SARPs Table 3.1 |
| **2024.1.1 ~ 2032.12.31** | **100%** | **0%** | **지침 별표6 제3호 (위 두 구간을 한 행으로 통합)** |
| 2033.1.1 ~ 2035.12.31 | 85% | 15% | 국제·국내 동일 |

국내 지침은 SARPs가 2024~2029 / 2030~2032로 나눈 두 행을 값이 같으므로 한 행으로 합쳤다. 값에 차이는 없다.

- `SGF_y`는 ICAO가 매년 공표하는 값이다. 엔진은 계산하지 않고 외부 입력 테이블에서 읽는다. 구조는 OGF와 동일한 `(SE_y − SE_(B,y)) / SE_y` 이다 (SARPs 3.2.2 Note 1).
- 2021~2023 구간: ICAO 공식 SGF가 0이라 결과는 항상 0 (§5-1 해소)

---

**C-09 · 운영사 개별 성장계수**

```
OGF_y = ( OE_y − OE_(B,y) ) / OE_y
```

| 변수 | 의미 |
|---|---|
| `OE_y` | 해당 연도 y의 운영사 CO₂ 배출량 (t) |
| `OE_(B,y)` | 해당 운영사의 **2019년 총 CO₂ 배출량의 85%** (t) |
| `OGF_y` | 결과는 **퍼센트(성장률)** 이다. 배수가 아니다 |

- 국제 근거: SARPs 3.2.4 / 3.2.5
- 국내 근거: **지침 별표6 제4호** (원문 이미지 대조 확인, 2026-09-22)
- 예외: 영 제9조(지침 원문은 "영 제7조"로 오기, §5-2 해소) 각호의 상쇄의무 이행 특례 대상이거나 2019년 국제항공 탄소배출 실적이 없는 신규 운영사는 `OE_(B,y)`에 **10,000톤**을 적용한다.
- **검산 (ETM 그림 4-4, 2034년)**: OGF = 53.63%, OE_y = 11,000,000 → OE_(B,y) = 11,000,000 × (1 − 0.5363) = 5,100,700 t → 2019년 배출량 ≈ 6,000,824 t. 2019년 600만 t에서 2034년 1,100만 t으로 성장한 운영사로 정합적이다.
- 구조 이해: SGF도 같은 형태 `(SE_y − SE_(B,y)) / SE_y` 이다 (SARPs 3.2.2 Note 1). OGF는 부문 전체 대신 **해당 운영사 자신의 2019년 기준선** 대비 성장률을 쓰는 것뿐이다. C-08에서 SGF와 나란히 곱해지므로 반드시 같은 단위(%)여야 한다.
- 인수·합병 처리: 완전 인수 또는 완전 합병 시 2019년 기준배출량은 합산한다. 부분 인수 등 그 외의 경우 2019년 기준배출량은 변경하지 않는다 (ETM 4.3.2).
- 구현 주의: %O가 0%인 구간(2024~2032)에서는 OGF가 결과에 영향을 주지 않지만, 값 자체는 계산해 보고서에 남긴다. `OE_y = 0`인 경우 0으로 나누기가 발생하므로 가드한다.

### 모듈 `cef_reduction` — 적격연료 배출감축량

**C-10 · 적격연료 사용에 따른 감축량**

```
ER_y = FCF × [ Σ_f MS_(f,y) × ( 1 − L_CEF / LC ) ]
```

| 변수 | 의미 | 단위 |
|---|---|---|
| `ER_y` | 연도 y의 적격연료 사용에 따른 탄소 감축량 | t |
| `FCF` | 연료전환계수 (3.16 / 3.10) — **합계 밖에서 한 번만 곱해짐** | tCO₂/t |
| `MS_(f,y)` | 연도 y의 지속가능 항공연료(저탄소 항공유 포함) f의 질량 | t |
| `L_CEF` | 적격연료의 수명주기 배출량 값 | gCO₂e/MJ |
| `LC` | 항공연료의 수명주기 기준 배출량 | gCO₂e/MJ |

- 국제 근거: SARPs 3.3.1 ~ 3.3.3
- 국내 근거: **지침 제9조②, 별표6 제5호·제6호** (원문 스크린샷 대조 확인, 2026-09-22)
- `LC` 기준값: Jet-A / Jet-A1 / Jet-B / TS-1 / No.3 = **89**, AvGas = **95**
- `L_CEF` 출처: 기본값은 ICAO 「CORSIA Default Life Cycle Emissions Values for CORSIA Eligible Fuels」, 실제값은 ICAO 「CORSIA Methodology for Calculating Actual Life Cycle Emissions Values」에 따라 승인된 지속가능성 인증제도가 검증한 값.
- **구현 주의: `FCF`는 합계(Σ_f) 밖에서 한 번만 곱해진다.** 연료 종류별로 FCF가 다름에도(Jet 계열 3.16 / AvGas 계열 3.10) 식 구조상 단일 값만 적용된다. 한 신고서 안에 Jet 계열과 AvGas 계열 적격연료가 **동시에** 존재하는 입력을 어떻게 처리할지는 원문에 명시되지 않았다 (실무상 대부분 Jet 계열 SAF만 존재해 드러나지 않는 경우로 추정). 엔진은 연료 종류가 혼재된 입력이 들어오면 예외를 발생시키거나 종류별로 별도 계산 후 합산하도록 방어 로직을 둔다.
- 적격 요건 4가지 (지침 제6조) — 모두 충족해야 감축 인정:
  1. 「석유 및 석유대체연료 사업법」 제24조 품질기준 + ICAO CORSIA 지속가능성 기준 충족
  2. ICAO가 정한 인증제도(ISCC, RSB 등)로 인증된 연료만 사용, 사용 여부 입증 가능
  3. 해당 실적을 **타 온실가스 감축 실적에 사용하지 않을 것**
  4. 일반 항공유와 공동 인프라에서 혼합된 경우 구매내역 증빙 가능
- 보고 절차: 이행기간 종료 전 집계 → 별지 제3호서식 작성 → 증빙 첨부 → 검증기관 검증 → 국토부 제출 (지침 제7조①)
- 제3자 거래·판매 시 변경 보고 의무 (지침 제7조④)

### 모듈 `final_offset` — 최종 상쇄의무량

**C-11 · 이행기간 총 최종 상쇄의무량**

```
FOR_c = Σ(y=1..3) OR_(y,c) − Σ(y=1..3) ER_(y,c)
```

| 변수 | 의미 | 단위 |
|---|---|---|
| `FOR_c` | 이행기간 c의 총 최종 상쇄의무량 | t |
| `OR_(y,c)` | 이행기간 c의 y년차 상쇄의무량 | t |
| `ER_(y,c)` | 이행기간 c의 y년차 적격연료 감축량 | t |

- 국제 근거: SARPs 3.4.1
- 국내 근거: **지침 제9조①, 별표6 제1호**
- **끝수 처리: 톤 단위로 올림한다** (SARPs 3.4.4 "rounded up to the nearest tonne"). 국문 번역본과 지침 제9조①·별표6 제1호는 "반올림"으로 적었으나, ICAO 기준 단일 적용 방침에 따라 영문 원문을 따른다 (v1.6).
- **음수 처리: 결과가 음수이면 "0"으로 간주한다.** 다음 이행기간으로 이월하지 않는다 (SARPs 3.4.3).
- 이행기간 정의: 2021년부터 기산한 매 3년 단위 (영 제9조①1)

---

**C-12 · 면제 판정 및 EU-ETS 조정**

| 판정 | 조건 | 근거 |
|---|---|---|
| 면제 ① | 직전 이행기간 통보받은 총 상쇄의무량 < 3,000 t | 영 제9조①1 / SARPs 3.4.2 |
| 면제 ② | 국제항공운송사업 면허 첫해 포함 3년이 되는 해의 12/31 미경과 + 국제운항 개시 후 총 배출량이 2019년 세계 국제항공 배출량의 1/1000 이하 | 영 제9조①2 |
| **EU-ETS 조정** | EU 역내 구간 배출량을 EU-ETS 배출권 구매로 상쇄한 경우 **해당 구간 배출량을 상쇄의무량 산정에서 제외** | **지침 제9조③** |

- EU-ETS 조정은 ICAO 표준에 없는 **국내 고유 조항**이다. 입력 데이터에 "EU 역내 구간 여부"와 "EU-ETS 상쇄 여부" 플래그가 필요하다.
- 면제 판정은 `final_offset` 모듈의 마지막 단계에서 수행하고, 면제 사유를 결과 객체에 문자열로 남긴다.
