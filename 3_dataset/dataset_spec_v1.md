## 5. 골든 케이스 사용법

`golden_cases.csv`는 ICAO가 문서로 공개한 계산 예시다. 우리 코드가 **국제기구 계산과 일치함을 증명**하는 근거이므로, 단위테스트는 여기서 시작한다.

```python
# 예: 방법 A 단위테스트
def test_method_a_golden():
    assert method_a(T_N=94.6, T_next=50.3, U_next=43.3) == 87.6   # GA-1
    assert method_a(T_N=9.6,  T_next=75.1, U_next=71.7) == 6.1    # GA-4, 무급유 예외
```

**주의 — ETM 표 3-3 ~ 3-7은 서로 독립된 예시다.** 같은 5편을 다룬 것처럼 보이지만 표마다 입력값이 조금씩 다르다 (예: 2번 항공편의 블록오프 연료가 표3-3은 50.3, 표3-5는 51.8). 하나의 일관된 데이터셋으로 합치려 하면 안 되고, 케이스별로 분리해서 써야 한다. `golden_cases.csv`를 `case_id` 단위로 만든 이유다.

`boundary_cases.csv`는 국내 고유 규칙용이며, ICAO에 대응 예시가 없으므로 **우리가 손으로 계산한 기대값**이다. 팀 내 2인이 각자 계산해 대조한 뒤 확정하기를 권한다.

## 6. 알려진 한계

| 번호 | 내용 |
|---|---|
| 1 | `SGF_2024 = 0.15405257`은 ICAO **2024년 공식값**(「CORSIA Annual SGF」 4th ed. Rev.1, 2025-12-12)으로, 가정값이 아닌 실제값이다. (v1.1까지는 가상값 0.1820, v1.2~v1.3은 이 값을 2027년 시나리오에 대용) |
| 2 | 연료 소비량은 기종별 대표값에 ±6% 난수를 준 것이다. 실제 운항 프로파일(적재량, 항로, 기상)을 반영하지 않는다 |
| 3 | 2019년 기준배출량(`OE_2019_total`)은 2024년 배출량과 정합적인 가상값이다 |
| 4 | 공항쌍 기준으로만 생성했다. 국가쌍 기준 검증이 필요하면 공항쌍을 집계해 만들면 된다 |
| 5 | CERT 입력 데이터(대권거리 등)는 포함하지 않았다. C-07은 판정 로직까지만 구현하고 배출량 값은 외부 입력으로 받기로 했으므로 (calc_spec §2 C-07) 현 단계에서는 불필요 |
| 6 | `flights_*.csv`가 각각 약 3MB다. 판다스로는 문제없지만 엑셀로 열면 느릴 수 있다 |

## 7. 다음 단계에서 쓰는 법

```
flights_clean.csv + aircraft.csv + params.csv
        → fuel_use      (C-01~C-05)   → 항공편별 연료 사용량
        → co2           (C-06, C-07)  → 연간 CO₂ 1,899,987 t 재현되면 정상
        → offsetting    (C-08, C-09)  → OR_2024
   saf_batches.csv
        → cef_reduction (C-10)        → ER_2024
        → final_offset  (C-11, C-12)  → FOR_(2024-2026)

flights_dirty.csv + error_injection_log.csv
        → 검증엔진 → 미탐·오탐 측정
```

계산엔진이 `flights_clean.csv`로부터 **1,899,987 t**을 재현하면 1차 관문 통과다.
