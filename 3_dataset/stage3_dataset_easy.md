# 3단계 — 가상 데이터셋 설계 (쉽게 풀어쓴 버전)

> 이 문서는 팀원 누구나 배경지식 없이 읽을 수 있도록 쉽게 푼 요약입니다.
> 정확한 파일 구조가 필요하면 `dataset_spec_v1.md`(v1.1)와 `dataset/` 폴더를 보세요.

---

## 이 단계에서 한 일을 한 문장으로

**"진짜 항공사 데이터가 없으니, 우리가 직접 가짜 항공사와 가짜 비행 기록 2만 편을 만들었다."**

## 왜 이 작업이 필요했나

계산기(4단계)와 검사 로직(5단계)을 만들려면 **넣어볼 데이터**가 있어야 합니다. 그런데 실제 항공사의 비행 데이터는 우리가 가질 수 없습니다(기밀이기도 하고, 애초에 없기도 합니다). 그래서 진짜처럼 그럴듯한 **가짜 데이터**를 직접 만들었습니다.

## 그냥 아무렇게나 만들면 안 되는 이유

여기가 중요한 포인트입니다. 가짜 데이터를 아무렇게나 만들면 "계산기가 돌아가긴 하네" 정도만 확인할 수 있습니다. 우리는 두 가지를 확인하고 싶었습니다.

1. **정상적인 데이터를 넣었을 때, 계산이 정확히 맞는가?**
2. **일부러 이상한 데이터를 넣었을 때, 검사 로직이 진짜로 그걸 잡아내는가?**

그래서 데이터를 두 벌 만들었습니다.

| 데이터 | 비유 |
|---|---|
| **정상본** (19,672편) | 시험 문제의 "정답이 다 맞는 답안지" |
| **오류주입본** | 같은 답안지인데 일부러 22곳에 틀린 답을 써넣은 것 |

이렇게 하면 "우리 검사 로직이 정상본은 안 건드리고, 오류주입본에서는 딱 그 22곳만 정확히 잡아내는가"를 시험해볼 수 있습니다.

## 숫자를 왜 하필 이렇게 맞췄나

**총 배출량 190만 톤은 국내 중형 항공사 정도의 규모입니다.** 처음엔 2단계에서 발견한 "국제 기준과 국내 기준이 갈리는 애매한 구간(50만~500만 톤)"을 재현하려고 이 규모로 맞췄는데, 나중에 국제 기준(ICAO)만 따르기로 확정되면서 그 목적은 사라졌습니다. 지금은 50만 톤을 넘는 규모라 오차 허용 범위 2%가 적용됩니다.

**기준 연도는 2024년입니다.** 처음엔 2027년으로 만들었다가, 상쇄의무량 계산에 쓰는 국제 성장계수(SGF)의 실제 공식값이 있는 2024년으로 옮겼습니다. 날짜만 바뀌고 숫자는 그대로입니다.

## 일부러 심은 이상한 상황들 (예시)

- 기름을 급유했는데, 그 양이 비행기 연료탱크 용량보다 많다고 적힌 경우 (물리적으로 불가능)
- 비행 전 연료량보다 비행 후 남은 연료가 더 많다고 적힌 경우 (역시 불가능)
- 국내선인데 국제선이라고 잘못 표시된 경우
- 무게가 아주 가벼운 소형기(경계값 근처)를 하나 넣어서 "의무 대상에 들어가나 안 들어가나" 애매한 경우까지 테스트

## 산출물

| 파일 | 무엇인가 |
|---|---|
| `flights_clean.csv` / `flights_dirty.csv` | 정상 비행 기록 / 오류 심은 비행 기록 |
| `aircraft.csv` | 가상 항공사의 비행기 27대 목록 |
| `saf_batches.csv` | 친환경 연료 사용 기록 |
| `golden_cases.csv` | 국제기구가 공식적으로 공개한 "정답이 확실한" 계산 예시 28개 |
| `boundary_cases.csv` | 애매한 경계선(딱 기준값과 같은 경우) 테스트용 22개 |
| `documents.json` / `documents_dirty.json` | 정상/오류 서류 샘플 (계산이 끝난 뒤 5단계에서 추가) |

## 이 단계에서 알아두면 좋은 용어

| 용어 | 쉬운 뜻 |
|---|---|
| 골든 케이스 | 정답이 이미 공식적으로 공개되어 있어서, 우리 계산 결과와 비교하면 맞는지 바로 확인 가능한 예제 |
| 경계값 테스트 | 기준이 "5,700kg 초과"일 때, 정확히 5,700kg인 경우를 일부러 넣어서 부등호 방향(이상이냐 초과냐)이 코드에 제대로 반영됐는지 확인하는 것 |
| 오탐 / 미탐 | 2단계 문서 참고 — 정상을 이상하다고 하는 실수 / 이상한 걸 놓치는 실수 |
| MTOW | 비행기 최대이륙중량. 이게 일정 기준(5,700kg)을 넘는 비행기만 이 제도의 대상이 됨 |

## 다음 단계와의 연결

이 데이터를 4단계(계산기)에 넣으면 190만 톤이 정확히 나와야 하고, 5단계(검사 로직)에 넣으면 정상본은 통과, 오류주입본은 딱 심은 곳만 걸려야 합니다. 실제로 두 단계 다 그렇게 됐습니다(4단계: 190만 톤 정확히 재현, 5단계: 오탐 0건·미탐 0건).
