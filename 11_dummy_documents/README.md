> 2026-11-01 작성. 실제 항공사 서류는 영업기밀이라 볼 수 없어(멘토님 회신), 3단계 가상 데이터(`engine/dataset/`)를 ICAO 서식에 채운 서류 세트입니다. 박사님께 「실제와 비슷하고 앞뒤가 맞는지」 검토받는 용도이며, 원래 11단계의 실데이터 검증을 대신합니다.

## 만든 방법

- **원본 서식 보존**: ICAO 서식 파일을 다시 저장하지 않고, 입력 칸(서식의 연두색 칸)에만 값을 써 넣었습니다. 시트, 선택 목록, 서식이 원본 그대로입니다.
- **가정 표시**: 데이터에 없는 값은 가정했고, 이름·주소에는 「(가상)」, 이메일에는 `.example` 주소를 썼습니다. 어느 칸이 가정인지는 `가상서류세트_칸별값_v1.xlsx`에 있습니다.
- **쓰지 않는 칸**: 한빛항공은 Block-off/Block-on 방법, 공항쌍 보고, 적격연료 2배치라서 다른 방법·국가쌍 시트·남는 열은 비웠습니다.

## 알려 둘 점

1. 검증보고서 서식 「Time Allocation and Scope」 C55의 `#REF!`는 **ICAO 원본 서식에 원래 있는 오류**입니다.
2. 적격연료 공급사 이름은 가상 데이터에 있던 실제 회사명이라 「(가상 시나리오)」를 붙였습니다.
3. 적격연료 배치 1의 전주기 배출값(24.0 gCO2e/MJ, 기본값)은 가상 값이라 ICAO 기본값표와 다를 수 있습니다. 박사님 검토 때 확인할 항목입니다.
4. OoM(국가 점검표)은 항공사 제출 서류가 아니라 제외했습니다.
5. 카탈로그(`field_master.xlsx`)의 표 범위 중 일부는 안내 문장 줄을 포함하고 있어, 범위 전체가 아니라 실제 입력 칸에만 썼습니다.
