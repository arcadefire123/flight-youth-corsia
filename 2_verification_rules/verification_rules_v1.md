## 0. 설계 원칙

**계층 구분의 근거** — 붙임2-2 9주차(형식·임계값), 10주차(일관성·정성)를 그대로 따른다.

| 계층 | 판정 주체 | 판정 결과 | 본 문서 ID |
|---|---|---|---|
| 형식 | 코드 | 참/거짓 | `F-xx` |
| 임계값 | 코드 | 참/거짓 | `T-xx` |
| 일관성 | 코드 | 참/거짓 | `X-xx` |
| 정성 | LLM | 충분/보완 필요 | `Q-xx` |

**심각도와 최종 검증의견의 관계**

검증의견은 ICAO 부속서 16 제4권 부록 6 3.10의 3종을 따른다. 규칙 위반을 여기로 수렴시킨다.

| 심각도 | 의미 | 최종 의견 귀결 |
|---|---|---|
| `치명` | 중대한 허위진술·부적합 (중요성 임계치 이상) | **불만족** (verified as unsatisfactory) |
| `차단` | 검증 범위가 너무 제한적이거나 데이터를 충분히 신뢰할 수 없음 | **불만족** |
| `중요` | 중대하지 않은 허위진술·부적합 | **의견부 만족** (satisfactory with comments) — 내용을 명시 |
| `경미` | 주의·확인 사항 | **의견부 만족** — 내용을 명시 |
| 위반 없음 | | **만족** (verified as satisfactory) |

v1.6까지는 환경부 검증지침 제16조②의 국내 4종(적정/조건부 적정/부적정/검증 불가)을 썼으나, ICAO 기준만 적용하기로 확정되어 v1.7에서 교체했다.

ETM은 이를 **허위진술(misstatement)** 과 **부적합(non-conformity)** 으로 나눈다 (ETM 3.3.8.1). 두 체계를 함께 표기한다.

- 허위진술 = 보고서의 오류·누락·허위 보고
- 부적합 = 승인된 EMP 또는 SARPs 요건에 맞지 않는 행위/누락
- 부적합으로 인해 데이터에 오류가 생기면 그 부적합은 허위진술로도 본다

### 2.1 중요성(materiality) 기준 — ICAO 기준으로 확정

**ICAO 부속서 16 제4권 부록 6 3.5.1만 적용한다.** 연간 국제선 배출량 50만 t 초과 2%, 50만 t 이하 5%.

v1.6까지는 국제 기준(2단계)과 환경부 검증지침 별표3 제5호 다목(3단계: 2.0%/2.5%/5.0%)이 50만~500만 t 구간에서 서로 달라, 두 기준을 병기 계산하고 더 엄격한 쪽으로 판정했다. 검증지침 별표3은 국내 배출권거래제 "할당대상업체"용으로 작성된 조항이라 CORSIA 이행의무자에 그대로 적용하기 어려웠고, v1.7에서 ICAO 기준 단일 적용으로 확정했다.

### 5.1 종합점수 (9단계에서 확정)

2차 멘토링에서 결과를 점수로도 보여주고 근거를 기록하라는 의견을 받았다. 위 3종 판정은 ICAO 기준이므로 그대로 두고, 웹 화면용 **보조 지표**로 종합점수를 붙인다. 9단계에서 **심각도 가중 + 판정별 상한** 방식으로 확정했다. 설계 근거와 대안 비교는 `9_web_design/web_design_v1.md` §2에 있다.

**배점**

| 심각도 | 배점 |
|---|---|
| 치명 | 5 |
| 중요 | 2 |
| 경미 | 1 |
| 정보 | 0 |

**산식**

```
계층 점수 = 100 × (1 − 해당 계층에서 잃은 배점 ÷ 해당 계층 총 배점)
원점수    = 100 × (1 − 전체 잃은 배점 ÷ 전체 총 배점)
전체 점수 = min(원점수, 판정별 상한)
```

- SKIPPED 규칙은 분모에서 제외한다. 판정 보류를 감점으로도 가점으로도 처리하지 않는다.
- **규칙 단위로 1회만** 계산한다. 위반 건수는 점수에 반영하지 않고 목록에만 표시한다 (오류주입본 X-19는 1,102건이라 건수를 반영하면 한 규칙이 점수를 지배한다).
- 상한은 **전체 점수에만** 적용한다. 계층별 점수는 보정 없이 원점수로 둔다.

**판정별 상한**

| 판정 | 상한 |
|---|---|
| 만족 | 100 |
| 의견부 만족 | 89 |
| 불만족 | 59 |

> 이 90·60 구간 기준은 **ICAO 기준이 아니라 우리 팀이 정한 보조 기준**이다. ICAO는 점수 체계를 두지 않는다. 화면·보고서에 그렇게 표기한다.

상한이 적용된 경우 **보정 전 원점수와 사유를 함께** 표시한다 — 예: `59.0점 (원점수 97.4 · 치명 위반으로 상한 적용)`. 상한을 두는 이유는, 치명 위반이 1건이면 원점수가 97.4점이 되어 판정(불만족)과 어긋나 보이기 때문이다.

**검증 결과 (엔진 v0.4.0 실측)**

| 입력 | 판정 | 원점수 | 전체 점수 | 형식 | 임계값 | 일관성 | 정성 |
|---|---|---|---|---|---|---|---|
| 정상본 | 만족 | 100.0 | 100.0 | 100.0 | 100.0 | 100.0 | 100.0 |
| 오류주입본 | 불만족 | 25.8 | 25.8 | 17.8 | 76.2 | 12.5 | 75.0 |

이 방식에서 「만족」은 위반 0건이므로 전체 점수가 항상 100.0이 된다. 종합점수는 의견부 만족·불만족 구간에서만 변별력을 가지며, 이는 "판정이 주, 점수가 보조"라는 원칙과 일관된다.

**근거 기록** — 점수가 나오면 규칙별 감점(`X-12 · 치명 · 배점 5/194 → −2.6점`), 계층 산식(`형식 = 100 × (1 − 37/45) = 17.8`), 상한 적용 여부를 함께 기록한다. 11단계 검증 보고서가 이 기록을 쓴다.

**구현 위치** — 웹이 아니라 **검증엔진 안**에서 계산한다. CLI와 웹이 같은 값을 내야 한다. (구현은 10단계 착수 시)

## 7. 이 규칙들이 가상 데이터셋에 요구하는 케이스

다음 단계(가상 데이터셋 설계)로 넘기는 요구사항이다. **아래 케이스가 데이터에 없으면 해당 규칙은 테스트할 수 없다.**

| 필요 케이스 | 검증할 규칙 |
|---|---|
| 정상 항공편 다수 (기준선) | 전체 |
| 급유 없는 항공편 + 연속 무급유 구간 | C-01 예외, C-04 배분 |
| 데이터갭 항공편 (갭 비율 4.9% / 5.1% 두 벌) | T-04, X-19, Q-06 |
| 블록온 > 블록오프인 이상 항공편 | X-21 |
| 탱크 용량 초과 급유 | X-20 |
| 항공편 일련번호 누락 | X-18 |
| 국내선 + 국제선 혼재 (연속 배치) | C-04, X-15 |
| 출발·도착이 같은 국가인 항공편 | X-15 |
| 동일 국가쌍에 연료 2종 사용 | X-14, 지침 별표4 5.1 비고2 |
| 편도만 있는 노선 | X-13 |
| 편당 평균 연료 250톤 초과 / 1톤 미만 노선 | T-07, T-08 |
| SAF 사용분 (기본값·실제값 각 1건) | C-10, X-06 |
| EU 역내 구간 + EU-ETS 상쇄 | X-23 |
| 배출량 합계가 노선별 합계와 1톤 어긋나는 오류본 | X-10 |
| 국가쌍(5.1)과 공항쌍(5.2)이 **둘 다 채워진** 오류본 | X-09 |
| 동일 노선에서 Jet-A1과 AvGas를 함께 쓴 항공편 | X-14b |

| 연간 배출량이 **정확히 10,000t**인 케이스 | T-01 (경계값) |
| 배출권 일련번호가 XYZ001~005, XYZ007~050으로 끊긴 케이스 | F-21 |
| 연간 배출량 49,000 t / 51,000 t 두 벌 | T-02, C-07 |
| 상쇄의무량 합계 2,999 t 케이스 | T-05 |
| ΣER > ΣOR (FOR 음수) 케이스 | T-11, C-11 |
| 서술 항목이 부실하게 채워진 EMP 1부 | Q-01 ~ Q-05 |

정상 데이터 1벌과 **오류 주입본(dirty) 1벌**을 쌍으로 만드는 구조가 효율적이다. 정상본에서는 모든 규칙이 통과하고, 오류본에서는 의도한 규칙만 정확히 걸려야 한다. 걸리지 말아야 할 규칙이 걸리면 **오탐(false positive)** 이고, 이것도 정확도 지표에 포함한다.
