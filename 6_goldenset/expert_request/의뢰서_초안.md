# 골든셋 본편 작성 의뢰 내용

교수님·기업 멘토님 검토 요청 | 팀 비행청년 | 2026년 10월 29일 작성

교수님과 기업 멘토님께서 검토해 주신 뒤 박사님께 전달드리려는 의뢰 내용입니다. 고치실 부분이 있으면 말씀해 주세요. 바로 수정하겠습니다.

## 1. 부탁드리려는 일

첨부한 「골든셋_작성양식_v1.xlsx」의 「1_작성할항목」에 있는 서류 항목마다 아래 7가지를 채워 주시는 일입니다. 같은 내용이 양식 「0_작성안내」 탭에도 적혀 있어, 박사님께서 양식만 보셔도 하실 수 있게 했습니다.

| 성격 | 뜻 | 쓰는 방식 |
|---|---|---|
| 주체 | 이 칸을 작성·수행하는 쪽 | 목록에서 선택 |
| 단계 | 절차상 어느 단계인지 | 목록에서 선택 |
| 의무성 | 반드시 써야 하는지 | 목록에서 선택 |
| 시점·기한 | 언제까지인지 | 직접 입력 (예: 매년 4/30) |
| 입력유형 | 숫자·선택·글 등 어떤 형태인지 | 목록에서 선택 |
| 근거 | 규정 출처 | 직접 입력 |
| 연결필드 | 다른 서류에서 값이 같아야 하는 칸 | 직접 입력 (없으면 「-」) |

## 2. 분량

- 분량은 **50건**입니다. 「1차」 30건을 먼저, 여유가 되시면 「2차」 20건까지 부탁드리려 합니다.
- **1차 30건**: 서식 6종에서 항목 수에 비례해 골고루 뽑은 대표 표본입니다(종류마다 최소 3건). 이 30건만으로도 서식 종류별 대략의 정확도를 채점할 수 있습니다.
- **2차 20건**: 같은 방법으로 더 뽑은 것으로, 이어서 해 주시면 종류별 정확도를 더 안정적으로 볼 수 있습니다.
- 50건은 첫 프로젝트 계획서에 언급되어 있던 정답 데이터 규모를 기준으로 제안드리는 것이며, 박사님의 여건에 맞춰 분량은 조정할 수 있습니다. 분량이 과하다고 판단하신다면 줄이겠습니다.

## 3. 참고로 함께 드리는 자료

- **팀이 합의한 판정 기준**: 양식 「4_판정기준」(견본 기준 1~8번)과 첨부 PDF입니다. PDF의 9·10번은 저희 항목 카탈로그를 정리하는 기준이라 박사님께는 해당하지 않습니다.
- **확정 견본 5건**: 양식 「3_견본」입니다. 서식 종류별로 1건씩입니다.
- **기준과 다르게 판단하신 곳**: 양식의 「메모」 칸에 이유를 적어 주시면 기준을 보완하는 데 쓰겠습니다.

## 4. 항목 선정 방법

항목 카탈로그 667건에서 견본 5건과 템플릿 정보 줄을 빼고, 같은 항목이 반복되는 줄은 하나만 남긴 뒤 서식 종류별 비율대로 골랐습니다. 무작위 시드를 기록해 두어, 같은 방법으로 다시 뽑으면 같은 결과가 나옵니다. 서식별 개수는 1차가 EMP 8·ER 4·CEF 5·OoM 7·EUCR 3·VR 3, 2차가 EMP 4·ER 3·CEF 4·OoM 5·EUCR 2·VR 2입니다.

## 5. 결과 활용

보내 주신 답은 저희 AI 자동 분류 결과를 채점하는 정답으로 사용합니다.
