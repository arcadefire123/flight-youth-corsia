# 비행청년: CORSIA 서류 자동 검증 프로토타입

항공사가 제출하는 **CORSIA(국제선 항공 탄소 상쇄·감축 제도) 배출량 서류**를, **코드는 정확한 계산과 규칙을, AI는 글을 읽는 일만** 맡아 검증하는 도구입니다. 아주대학교 파란학기제 2026-2 기업 제안 프로그램에서 팀 「비행청년」이 만들었습니다.

> English summary: A prototype that checks airlines' CORSIA emissions documents. Deterministic code does the calculation and rule checks; an LLM only reads free-text answers and its output is advisory. All data in this repository is synthetic (a fictional airline, "Hanbit Air").

## 이 저장소의 결과물 4가지

| 결과물 | 내용 |
|---|---|
| ① 항목 카탈로그 | ICAO 서식과 국내 서식의 점검 항목 667줄(입력 항목 492 + 제목 줄 175)에 주체·단계·의무성·시점·입력유형·근거·연결필드를 붙인 목록 (`1_document_map/field_master.xlsx`) |
| ② 계산엔진 | 표준 산식(연료 사용량 5가지 방법, CO2 배출량, 상쇄의무량)을 파이썬으로 구현 |
| ③ 검증엔진 | 검증 규칙 63개와 종합점수, AI 정성 검증(참고용) |
| ④ 검증 결과 | 가상 제출 서류 세트로 돌려 본 정확도와 한계 |

## 한눈에 보는 결과

모든 수치는 **가상 데이터와 팀이 만든 정답지 기준이며 전문가 검토 전**입니다.

| 영역 | 결과 |
|---|---|
| 계산엔진 | ICAO 공식 예시 28/28 일치 |
| 검증엔진 | 정상 서류는 오탐 0건(종합점수 100.0, 판정 만족), 오류를 넣은 서류는 주입한 39종 전부 검출(종합점수 25.8, 판정 불만족) |
| 정성 검증 AI | 정답을 아는 시험 문제로 쟀을 때 최종 판정 일치 100.0%와 97.8%(입력 방식 2가지) |
| 항목 자동 분류기(혼합 방식, 골든셋 28건) | 주체·단계 100%, 의무성 89.3%, 시점·기한 89.3%, 입력유형 92.9%, 연결필드 64.3%, 근거 28.6%(정확 일치)·기본 인용 일치 64.3% |
| RAG 절차 안내 | 법령 4종을 407조각으로 나눠 근거 조항과 함께 답하고 인용을 코드가 확인(구현 완료, 정답률 평가 진행 중) |

주체·단계는 서식 종류로 정해지는 값이라 규칙이 맞힌 것이고 AI의 정확도가 아닙니다. 속성마다 따로 보고하며 평균 하나로 말하지 않습니다.

## 설계 원칙

- **코드는 정확한 일, AI는 글 읽는 일.** 최종 판정과 점수는 항상 코드가 계산하고 AI는 검토자 참고용입니다.
- **정답은 사람이 원문으로 정합니다.** AI에게 정답을 묻지 않고, 팀이 법령·서식 원문으로 합의한 기준(`6_goldenset/`)으로 AI를 채점합니다.
- **정직한 한계 표기.** 실제 항공사 서류는 영업기밀로 볼 수 없어 가상 서류로 검증했고, 수치는 전문가 검토 전입니다.

## 설치와 실행 (윈도우 · 아나콘다)

Anaconda Prompt에서 한 줄씩 입력합니다. 반드시 `engine` 폴더에서 실행합니다.

```
cd engine
python check_all.py
pip install -r requirements.txt
streamlit run app.py
```

`check_all.py`는 점검 10개 항목이 모두 통과해야 합니다. 화면은 기본 브라우저로 열리고, 끌 때는 `Ctrl + C`를 누릅니다. 웹 화면에서 샘플(정상본·오류주입본)을 고르거나 파일을 올려 결과를 확인합니다. 명령 한 줄로 전체를 실행하는 `python -m corsia full`도 있고, 웹과 같은 엔진을 씁니다.

### AI 기능(선택)

정성 검증·항목 분류기·RAG는 Anthropic API 키가 필요합니다. 키는 저장소에 넣지 않고 윈도우 사용자 환경 변수 `ANTHROPIC_API_KEY`에서만 읽습니다. 키가 없어도 계산·검증·웹은 동작합니다(정성 검증 영역은 작성 여부만 표시).

## 폴더 구성

| 폴더 | 내용 |
|---|---|
| `engine/` | 계산엔진·검증엔진·웹(`app.py`)·AI 기능 코드와 자동 시험 |
| `0_scope`~`5_verify_engine` | 단계별 설명(범위, 문서 지도, 검증 규칙, 가상 데이터 설계, 계산엔진, 검증엔진) |
| `6_goldenset/` | 골든셋(팀 정답지)과 판정 기준 |
| `7_qualitative/` · `7_rag/` | 정성 검증 AI와 RAG 절차 안내 |
| `8_classifier/` | 항목 자동 분류기의 규칙표·메모 |
| `9_web_design/` | 종합점수와 웹 화면 설계 |
| `11_dummy_documents/` | 가상 제출 서류 세트(한빛항공) |

전체 과정의 기록은 `corsia_project_guidebook.md`(가이드북)와 `project_status_index.md`(현황 인덱스)에 있습니다.

## 데이터와 저작권에 대하여

- 이 저장소의 모든 서류 데이터는 **가상**입니다(가상 항공사 「한빛항공」, 연료 공급사 이름도 「공급사 A(가상)」처럼 가상 표기). 실제 항공사 자료는 포함하지 않습니다.
- ICAO 서식 파일(ETM 부록 1의 엑셀 서식)에 가상 값을 채운 서류 세트는 서식의 재배포 조건을 확인하기 전이라 **공개 저장소에 넣지 않았습니다**(`11_dummy_documents/`). 세트의 구성과 만든 방법은 그 폴더의 README에 있고, 서식 원본은 ICAO ETM 부록 1에서 받을 수 있습니다.
- ICAO·ETM·SARPs 원문 파일도 넣지 않았습니다. 다만 `1_document_map/field_master.xlsx`는 서식의 항목 이름과 안내 문구를 발췌해 정리한 목록입니다.
